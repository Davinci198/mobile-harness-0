## 2. Findings noi (potențiale bug-uri)

> Rezolvate în acest commit: P1 SafFileSystem same-path guard; P2 `safely()` logging; P2 PocketDevApp state pe Main; P2 `pasteInto` index-based matching; P2 `latencyColor` refactor. Rămase deschise: P3 BundledSkills (mkdir masking, copyTree empty dirs), P3 Thread.sleep → delay.

### P1 — SafFileSystem.copy nu protejează copierea pe aceeași cale
- Locație: `storage/SafFileSystem.kt:187–215`
- Problema: `LocalFileSystem.copy` are guard `canonicalPath == canonicalPath`, dar SAF nu. La CUT în același folder pe SAF, `copy` citește bytes și scrie la aceeași URI (conținut păstrat), apoi `delete(source)` șterge fișierul → pierdere de date.
- Fix: guard în `SafFileSystem.copy` (compară URI sursă/destinație) și/sau în `FsClipboardRules.pasteInto`.

### P2 — `safely()` înghite excepțiile în tăcere
- Locație: `tools/network/NetworkTools.kt`
- Fix: log la nivel debug înainte de swallow.

### P2 — Mutare de stare Compose din thread de background
- Locație: `ui/PocketDevApp.kt` (install() pentru Studio și Hermes Dashboard)
- Fix: wrap în `withContext(Dispatchers.Main)`.

### P2 — `MemoryTools` sincronizare (verificat: deja acoperit)
- Locație: `tools/memory/MemoryTools.kt`
- Constat: metodele sunt `@Synchronized` (lock per-instanță), dar toate trec prin `execute()`, care deja face `synchronized(STORE_LOCK)` pe un lock static din companion object. Deci sincronizarea cross-instanță este deja asigurată. `@Synchronized` este redundant, dar inofensiv. Nicio modificare necesară.

### P2 — `pasteInto` potrivește sursa doar după basename
- Locație: `ui/MainViewModel.kt:2846–2896`
- Fix: păstrează maparea path-completă.

### P2 — `AgentScreen.latencyColor` folosește `!!` fragil
- Locație: `ui/AgentScreen.kt:201–202`
- Fix: extrage variabilă.

### P3 — `BundledSkills.ensure()` maschează eșecul `mkdirs()`
- Locație: `tools/skill/BundledSkills.kt`
- Fix: distinge cazurile.

### P3 — `copyTree` creează directoare goale pentru asset-uri nelizibile
- Locație: `tools/skill/BundledSkills.kt:copyTree`
- Fix: propagă excepția sau marchează în Report.

### P3 — `Thread.sleep` în bucle de polling
- Locații: `MainViewModel.kt:775,1331,2077`, `ClaudeRuntimeBridge.kt`, `DshRuntimeBridge.kt`, `HeadlessCliBridge.kt`, `HermesWarmSession.kt`
